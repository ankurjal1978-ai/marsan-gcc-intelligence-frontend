# MarSan GCC Intelligence frontend

Public assessment assets. Serve these files on the same origin as the private `/api/leads` endpoint. The frontend contains no savings coefficients or lead database credentials. Results unlock only after the API saves a lead. Static hosting alone will not process submissions.

Copy `calculator.html`, `calculator.js`, `style.css`, `favicon.svg`, and `privacy.html` into your website's public assets. Link to `/calculator.html` from the homepage and campaign pages. Replace the brief privacy notice with MarSan's approved policy before a broad campaign.
